# ระบบร้านอาหาร (POS)

เว็บแอปสำหรับร้านอาหารขนาดเล็ก รันบนคอมพิวเตอร์เครื่องหลักในร้าน แล้วเปิดจากแท็บเล็ตหรือมือถือที่ต่อ Wi‑Fi เดียวกันได้ทันที ไม่ต้องใช้อินเทอร์เน็ต (ยกเว้นฟอนต์ ถ้าไม่มีเน็ตจะใช้ฟอนต์ของเครื่องแทน)

## ทำอะไรได้บ้าง

| ส่วน | ความสามารถ |
|---|---|
| **ขายหน้าร้าน** | ผังโต๊ะ + ออเดอร์กลับบ้าน · กดเมนูเพิ่มรายการ ใส่หมายเหตุ (ไม่เผ็ด ฯลฯ) · ส่งครัว · สั่งเพิ่มหลายรอบ · ยกเลิกรายการ/ทั้งออเดอร์ · ย้ายโต๊ะ · พิมพ์ใบแจ้งยอด (มี QR พร้อมเพย์ให้สแกนที่โต๊ะ) |
| **ชำระเงิน** | เงินสด (ปุ่มแบงก์ลัด + คำนวณเงินทอน) หรือ QR พร้อมเพย์ที่ใส่ยอดให้อัตโนมัติ · ส่วนลดเป็นบาท · พิมพ์ใบเสร็จ |
| **ครัว** | จอครัวสำหรับแท็บเล็ต อัปเดตทันทีพร้อมเสียงแจ้งเตือน · สีบอกเวลารอ (10/20 นาที) · แตะขีดฆ่ารายการที่ทำแล้ว · เปิดพิมพ์ใบสั่งอัตโนมัติได้ |
| **เมนู** | เพิ่ม/ลบ/แก้ราคา · จัดหมวดหมู่ · สวิตช์ “หมด” ปิดเมนูได้ทันที (หรือกด “ของหมด” ในหน้าขาย) |
| **สต็อก** | รับของเข้า (บันทึกเป็นค่าใช้จ่ายวัตถุดิบอัตโนมัติ) · นับสต็อกด้วยมือ คำนวณว่าใช้ไปเท่าไร · แจ้งเตือนของใกล้หมด · เตือนเมื่อไม่ได้นับเกิน 7 วัน |
| **รายรับรายจ่าย** | ยอดขายเข้าเองอัตโนมัติ · จดค่าใช้จ่าย (วัตถุดิบ แก๊ส ค่าเช่า ค่าแรง ฯลฯ) · ปิดยอดเงินสดสิ้นวัน พร้อมตัวช่วยนับแบงก์/เหรียญ · ยกเลิกบิล/พิมพ์ใบเสร็จซ้ำ |
| **รายงาน** | ยอดขายรายวัน/รายเดือน (กราฟ + ตาราง) · เมนูขายดี · ค่าใช้จ่ายตามหมวด · กำไรคร่าวๆ · ดาวน์โหลด CSV เปิดใน Excel |

## ติดตั้งและเปิดใช้งาน

1. ติดตั้ง [Node.js](https://nodejs.org) เวอร์ชัน 22.13 ขึ้นไป (แนะนำ LTS ล่าสุด)
2. **Windows:** ดับเบิลคลิก `start.bat` — ครั้งแรกจะติดตั้งให้เอง แล้วเปิดเบราว์เซอร์ที่ `http://localhost:3000`
3. หรือใช้คำสั่ง:

```bash
npm install
```

```bash
npm start
```

ครั้งแรกระบบจะใส่ **ข้อมูลตัวอย่าง** (โต๊ะ 10 โต๊ะ เมนู 20 รายการ วัตถุดิบ 9 รายการ) ให้ลองใช้ได้เลย แก้หรือลบได้ตามต้องการที่หน้า เมนู / สต็อก / ตั้งค่า

### ตั้งค่าครั้งแรก (หน้า “ตั้งค่า”)

- ชื่อร้าน ที่อยู่ เบอร์โทร (แสดงบนใบเสร็จ)
- **หมายเลขพร้อมเพย์** (เบอร์มือถือ หรือเลขบัตรประชาชน/เลขผู้เสียภาษี) แล้วกด “ทดสอบ QR” ลองสแกนด้วยแอปธนาคาร
- ชื่อโต๊ะ, ขนาดกระดาษเครื่องพิมพ์ (58 หรือ 80 มม.), เงินทอนตั้งต้นในลิ้นชัก

## ใช้กับแท็บเล็ต / มือถือในร้าน

ตอนเปิดระบบ หน้าจอจะแสดงที่อยู่ เช่น `http://192.168.1.10:3000` (ดูได้ที่หน้า ตั้งค่า → “เปิดจากแท็บเล็ต / มือถือ” พร้อม QR ให้สแกน)

- **แท็บเล็ตในครัว:** เปิด `http://<IP เครื่องหลัก>:3000/#/kitchen` แตะ “แตะเพื่อเปิดเสียง” หนึ่งครั้ง แล้วกด “เต็มจอ”
- **พนักงานรับออเดอร์:** เปิดหน้าแรกจากมือถือ เลือกโต๊ะ กดเมนู แล้ว “ส่งครัว”
- ครั้งแรกบน Windows อาจมีหน้าต่าง Firewall ถาม ให้กด **อนุญาต (Private network)**
- แนะนำตั้ง IP ของเครื่องหลักให้คงที่ (ที่ router) เพื่อไม่ต้องเปลี่ยนลิงก์บ่อย

## เครื่องพิมพ์

ระบบพิมพ์ผ่านเบราว์เซอร์ ใช้ได้กับเครื่องพิมพ์ใบเสร็จความร้อน (thermal) 58/80 มม. ที่ติดตั้งไดรเวอร์ใน Windows แล้ว

- **ใบเสร็จ / ใบแจ้งยอด:** พิมพ์จากเครื่องแคชเชียร์ (เปิด “พิมพ์ใบเสร็จอัตโนมัติ” ได้ในตั้งค่า)
- **ใบสั่งครัว** มี 2 แบบ เลือกตามอุปกรณ์ที่มี:
  1. เครื่องพิมพ์ครัวต่อกับเครื่องแคชเชียร์ → เปิด “พิมพ์ใบสั่งครัวจากเครื่องที่กดส่ง” ในตั้งค่า
  2. มีเครื่อง/แท็บเล็ตในครัวที่ต่อเครื่องพิมพ์ → เปิดหน้าครัว แล้วเปิดสวิตช์ “พิมพ์อัตโนมัติ” (ตั้งค่าแยกแต่ละเครื่อง)
- **ไม่ให้มีหน้าต่างยืนยันการพิมพ์ทุกครั้ง:** ตั้งเครื่องพิมพ์ใบเสร็จเป็น Default printer แล้วเปิด Chrome ด้วย `--kiosk-printing` เช่นสร้าง shortcut:

```bash
"C:\Program Files\Google\Chrome\Application\chrome.exe" --kiosk-printing http://localhost:3000
```

## งานประจำวัน

1. **เปิดร้าน:** เปิด `start.bat` บนเครื่องหลัก
2. **ระหว่างวัน:** ขายที่หน้า “ขายหน้าร้าน” · ของหมดกด “ของหมด” แล้วแตะเมนู · ซื้อของ/จ่ายเงินจากลิ้นชัก จดที่ “รายรับรายจ่าย → ค่าใช้จ่าย” หรือ “สต็อก → รับของเข้า”
3. **ปิดร้าน:** “รายรับรายจ่าย → ปิดยอดเงินสด” นับเงินในลิ้นชัก กรอกยอด ระบบบอกว่าเกิน/ขาดเท่าไร
4. **สัปดาห์ละครั้ง:** “สต็อก → นับสต็อก” และดาวน์โหลดไฟล์สำรองข้อมูล

## สำรองข้อมูล

ข้อมูลทั้งหมดอยู่ในไฟล์เดียว `data/pos.db` (SQLite)

- ดาวน์โหลดสำรองได้ที่ ตั้งค่า → “ดาวน์โหลดไฟล์สำรองข้อมูล” (ได้ข้อมูลครบเสมอ แม้ระบบเปิดอยู่)
- ถ้าจะก๊อปไฟล์ `data/pos.db` ไปเก็บเอง ให้ปิดระบบก่อน เพราะระหว่างที่ระบบเปิดอยู่ ข้อมูลล่าสุดอาจยังอยู่ในไฟล์ `pos.db-wal`
- กู้คืน: ปิดระบบ แล้วนำไฟล์สำรองไปวางแทน `data/pos.db` (ลบไฟล์ `pos.db-wal` และ `pos.db-shm` ถ้ามี) แล้วเปิดระบบใหม่
- เปลี่ยนที่เก็บข้อมูลได้ด้วยตัวแปร `POS_DATA_DIR` และเปลี่ยนพอร์ตด้วย `PORT`

## หมายเหตุ

- ยอดขายนับตาม **วันที่ชำระเงิน** · ใบเสร็จเป็นใบเสร็จรับเงินอย่างง่าย ไม่ใช่ใบกำกับภาษีเต็มรูป
- กำไรคร่าวๆ = ยอดขาย − ค่าใช้จ่ายที่บันทึกไว้ (ไม่รวมค่าเสื่อม/ต้นทุนที่ไม่ได้จด)
- สต็อกไม่ตัดอัตโนมัติตามสูตรอาหาร ใช้การนับมือแทน
- ยังไม่มีระบบล็อกอิน: ทุกเครื่องในวง Wi‑Fi เดียวกันเปิดได้ทุกหน้า (รวมรายงาน) — ควรใช้ Wi‑Fi แยกสำหรับลูกค้า

## โครงสร้างไฟล์

```
server.js        API + เซิร์ฟเวอร์ (Express) + แจ้งเตือนเรียลไทม์ (Server-Sent Events)
db.js            ฐานข้อมูล SQLite (node:sqlite) + ข้อมูลตัวอย่าง
promptpay.js     สร้าง QR พร้อมเพย์ (มาตรฐาน EMVCo)
public/          หน้าเว็บ (HTML/CSS/JavaScript ไม่ต้อง build)
  js/pages/      หน้า ขาย ครัว เมนู สต็อก รายรับรายจ่าย รายงาน ตั้งค่า
```
